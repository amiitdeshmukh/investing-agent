# Architecture Decision Record

This file records accepted decisions. New entries include date, context,
decision, and consequences. Existing decisions are not silently rewritten after
implementation depends on them.

## ADR-001 — One repository, separate applications

**Decision:** Keep `frontend/` and `backend/` as separate top-level applications
inside one Git repository.

**Consequences:** They install, run, test, and deploy independently while their
contracts and changes remain reviewable together. Nested Git repositories are
not allowed.

## ADR-002 — Frontend stack

**Decision:** Use Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui,
Recharts, and pnpm. Boilerplate and UI primitives come from official CLIs.

**Consequences:** `pnpm-lock.yaml` is authoritative; no `package-lock.json` is
created. The frontend follows generated Next.js agent guidance for its installed
version.

## ADR-003 — Backend stack

**Decision:** Use Python, FastAPI, and Pydantic with uv dependency management.
Future agent/backtesting phases may add LangGraph, vectorbt, and FinRL.

**Consequences:** `uv.lock` is authoritative. `requirements.txt` is generated by
`uv export` for compatibility and is not hand-edited.

## ADR-004 — Groww integration through APIs

**Decision:** Integrate Groww through documented HTTP/streaming APIs rather than
installing its Python SDK.

**Consequences:** Provider authentication, rate limiting, retries, and response
normalization live in a backend adapter. No Groww package is installed during
foundation work.

## ADR-005 — Persistence

**Decision:** Use PostgreSQL 16 with TimescaleDB for authoritative structured
and time-series data; use Chroma as a rebuildable vector index.

**Consequences:** Migrations are explicit. Knowledge content remains in
PostgreSQL, while Chroma IDs provide retrieval linkage.

## ADR-006 — Communication

**Decision:** Use REST under `/api/v1` for request/response operations and one
WebSocket at `/ws/live` for all streaming events. Do not add GraphQL or gRPC.

**Consequences:** Pydantic schemas generate frontend types. WebSocket events are
notifications and REST remains the recovery/state path.

## ADR-007 — Paper-first safety

**Decision:** Default to paper trading forever unless an authenticated human
explicitly requests a mode change. The deterministic risk layer is not
bypassable by an agent.

**Consequences:** Holds and rejections are logged; confirmations are mandatory;
daily-loss halts survive process behavior; automatic graduation is prohibited.

## ADR-008 — No Docker configuration

**Decision:** Do not add Dockerfiles or Docker Compose.

**Consequences:** Local and production environments run applications and data
services directly through host tooling and must document prerequisites.
